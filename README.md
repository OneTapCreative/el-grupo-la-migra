# El Grupo La Migra De Miguel Chachora Cota Website

Premium blue/red/black music-service website inspired by the proven DJ JRV conversion structure.

## Before launch
1. Replace all photo placeholders with optimized WebP/JPG files.
2. Replace `https://example.com/` in index.html, robots.txt, and sitemap.xml with the real domain.
3. Add the real phone, booking email, Instagram/social URLs, service radius, and verified reviews.
4. Replace `images/og-cover.jpg` with a real 1200x630 social-sharing image.
5. Connect the quote form to a server endpoint/email service. The demo currently validates and confirms locally but does not email.
6. Submit sitemap to Google Search Console and verify Google Business Profile links once the domain is live.

## SEO included
- Search-focused title + meta description
- Canonical URL placeholder
- Open Graph + Twitter social metadata
- Schema.org MusicGroup JSON-LD
- Semantic headings and accessible navigation
- Mobile-first responsive design
- robots.txt
- sitemap.xml
- local/event keyword copy structure
- FAQ content for long-tail search intent
- performance-friendly static build

## Suggested image sizes
- Hero: 1600x1200 or larger
- Gallery: 1200x900
- OG cover: 1200x630
- Use WebP where possible and keep most images under ~250 KB.
